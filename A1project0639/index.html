When I open the HTML file directly on my own computer, there is a Client, which is the web browser I use to open the website. However, there is no Server because the file is opened directly from my computer without a server sending the website to the browser.

Reflection

One challenge I faced was arranging the elements and writing CSS so that the website looked organized. At first, I was not very familiar with how to use some CSS properties, so I tried different values, checked the results, and searched for more information when needed.

After completing A1, I understand more about how HTML is used to create the structure of a website, while CSS is used to style and organize its appearance. I also learned that creating a website takes several steps, from planning the structure to testing and adjusting the details.

If I could continue developing this website, I would improve the layout so that it works better on different screen sizes. I would also like to add more details and features to make the website more interesting and easier to use.
